# Актуальная навигационная база (необязательно)

По умолчанию планнер использует бесплатную базу X-Plane/Robin Peel (GNU GPL, AIRAC 2013.10)
из репозитория FlightGear — точки, трассы, VOR/NDB и ILS по всему миру. Она старая, поэтому
часть точек/трасс могла измениться, а SID/STAR/заходов (CIFP) в ней нет.

Чтобы получить актуальные точки, трассы и процедуры, положите сюда файлы из своей копии
X-Plane 11/12 (папка `Resources/default data/` или `Custom Data/` после обновления AIRAC):

```
data/navdata/
├── earth_fix.dat     # точки
├── earth_nav.dat     # VOR/NDB/DME/ILS
├── earth_awy.dat     # трассы
└── CIFP/             # процедуры SID/STAR/APPCH: UUEE.dat, ULLI.dat, ...
```

После перезапуска сервера появятся автовыбор SID/STAR под ВПП и реальные схемы заходов.
Файлы в этой папке не коммитятся в git (лицензия Navigraph/X-Plane не разрешает их распространение).
